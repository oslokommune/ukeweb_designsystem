Vue component

The component sets the role itself, so screen readers announce the message. The danger variant gets role="alert", because an error has to reach the user right away: the screen reader interrupts whatever it is reading. All the other variants get role="status", which waits until the screen reader is done with what it is reading. This role can be overridden, as there may be situations where warning messages need to be announced immediately by screen readers.
