File size formatter for javascript. Takes a number of bytes and returns a human readable string.

The value moves to the next unit (bytes → KB → MB → GB → TB, divided by 1024) when it reaches 500. Values below 5 are shown with one decimal, values of 5 and above are shown without decimals, both rounded. Example: 150 000 bytes becomes 146 KB and 800 000 000 bytes becomes 0,7 GB.

OdsFileSize.format(bytes, options);

Usage in a project:

import OdsFileSize from '@oslokommune/oslo-designsystem/src/general/helpers/filesize/filesize'; OdsFileSize.format(150000); // "146 KB" OdsFileSize.format(800000000); // "0,7 GB" OdsFileSize.format(document.file.size); // e.g. "1,4 MB" for an attachment

The arguments are:

  • bytes

    Number. Required. The file size in bytes.

  • options

    Object. Optional. Default {}.

The options are:

  • locale

    The locale used for number formatting. Default is no-NO (decimal comma).

  • threshold

    The value at which the formatter moves to the next unit. Default is 500.

  • units

    The unit labels. Default is ["bytes", "KB", "MB", "GB", "TB"].
