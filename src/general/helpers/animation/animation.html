The animations helper is used to animate different types of elements. All animations share the same durations and easings, and are turned off for users who prefer reduced motion.

How to use

Add the class .ods-animation to the element, then add the desired type of animation afterwards. The following animations are supported:

  • .ods-animation--rotate: Used to rotate the ::after element. Add .ods-animation--rotate-open to rotate it 180 degrees.
  • .ods-animation--rotate-plus-minus: Used to rotate and toggle the ::after element between plus and minus icon. Add .ods-animation--rotate-plus-minus-open to rotate it and show the minus icon.
  • .ods-animation--fade: Fades the element in and out. Collapsible content fades automatically when it is collapsed. Outside a collapsible, toggle .ods-animation--fade-hidden from your own javascript to hide and show the element.
  • .ods-animation--pulse: A repeating ring that expands from the element. Used for status indicators that need attention, like the critical alert.

The rotate animations target the ::after pseudo element of the element, and expect it to be absolutely positioned with top: 50%, like the icon on the accordion trigger.

If the element also has the class .ods-collapsible-trigger, the collapsible helper javascript will toggle the open class for you when the trigger is clicked. This is how the accordion component animates its icons.

Durations and easings are defined as tokens in system/_animation.scss. Components should use these tokens instead of hard coded values. The same file contains the reduced-motion mixin, which wraps styles in a prefers-reduced-motion: reduce media query, and the shared ods-pulse keyframes.
