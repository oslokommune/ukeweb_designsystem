Phone number formatter for javascript. Based on the writing rules from Språkrådet.

Eight digit numbers are grouped in pairs (22 33 44 55), 800-numbers are grouped 3-2-3 (800 33 333), five digit numbers are written without spaces (02180) and six digit harmonized numbers are grouped 3-3 (116 117). The groups are separated with hard spaces so the number is not wrapped across lines. A Norwegian country code (+47 or 0047) is normalized to +47.

OdsPhone.format(number, options);

Usage in a project:

import OdsPhone from '@oslokommune/oslo-designsystem/src/general/helpers/phone/phone'; OdsPhone.format('22334455'); // "22 33 44 55" OdsPhone.format('+47 987 65 432'); // "+47 98 76 54 32" OdsPhone.format('80033333'); // "800 33 333" OdsPhone.format('02180'); // "02180"

The arguments are:

  • number

    String or number. Required. Existing spaces and punctuation are stripped before formatting.

  • options

    Object. Optional. Default {}.

The options are:

  • separator

    The separator between digit groups. Default is a hard space ( ).

Numbers with a non-Norwegian country code and numbers with an unknown length are returned cleaned but ungrouped.
