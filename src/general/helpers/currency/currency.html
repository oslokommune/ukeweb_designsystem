Currency formatter for javascript. Based on ruleset established in the service www.oslo.kommune.no.

Amounts are rounded to the nearest whole krone by default, following the principle used in calculators on oslo.kommune.no. Remember to inform the user that amounts are rounded when presenting calculated results. Thousands are grouped with a hard space and the decimal separator is a comma (Norwegian locale).

OdsCurrency.format(amount, options);

Usage in a project:

import OdsCurrency from '@oslokommune/oslo-designsystem/src/general/helpers/currency/currency'; OdsCurrency.format(1234.56); // "1 235 kroner" OdsCurrency.format(1234.56, { decimals: 2 }); // "1 234,56 kroner" OdsCurrency.format(1500000, { unit: 'kr' }); // "1 500 000 kr" OdsCurrency.format(1500, { unit: '', prefix: 'kr ' }); // "kr 1 500"

The arguments are:

  • amount

    Number (or numeric string). Required.

  • options

    Object. Optional. Default {}.

The options are:

  • locale

    The locale used for number formatting. Default is no-NO.

  • decimals

    Number of decimals shown. The amount is rounded to this precision. Default is 0 (nearest whole krone).

  • unit

    The unit appended after the amount, separated with a hard space. Default is kroner. Use kr for a short unit or "" for no unit.

  • prefix

    The prefix of the string. Default is "".

  • suffix

    The suffix of the string. Default is "".
